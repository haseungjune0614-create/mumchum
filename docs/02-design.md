# 설계

## 핵심 원칙: 멈춤 → 끊기 → 확인

사기 유형마다 대처법이 다르면 어르신이 기억하기 어렵습니다. 그래서 모든 시나리오의 정답 행동을 세 단어로 묶었습니다.

1. **멈춤**: 바로 보내거나 누르지 않기
2. **끊기**: 전화·문자 대화를 끊기
3. **확인**: 내가 아는 원래 번호로 직접 전화하기

## 분기 구조

- 시나리오마다 실제 문자·전화 화면으로 시작합니다.
- 첫 선택에서 의심하지 않으면, 두 번째 단계에서 사기범의 압박 문구("급해서 그래", "가족에게도 말하면 안 됩니다")가 나옵니다. 의심하다가도 흔들리는 순간을 연습하기 위해서입니다.
- 결말은 안전 / 아슬아슬 / 피해 세 종류입니다. 피해 결말도 구체적으로 보여 줘서 "그 선택을 하면 어떻게 되는지"를 체감하게 했습니다.
- 모든 결말 뒤에 "이것만 기억하세요" 3줄을 보여 줍니다.

전체 흐름은 [시나리오 분기 지도](scenario-map.md)에 있습니다.

## 어르신 사용성 기준

| 결정 | 이유 |
| --- | --- |
| 기본 글씨 20px, "글씨 크게" 24px | 노안 고려, 한 번 누르면 계속 유지 |
| 버튼 높이 64px 이상, 번호 표시 | 손가락으로 누르기 쉽고 "몇 번 눌러" 안내 가능 |
| 한 화면에 질문 하나, 선택지 2~3개 | 고민할 거리를 줄임 |
| 소리로 듣기 | 글 읽기가 힘든 분도 사용 |
| 단어 단위 줄바꿈 | 한글이 글자 중간에서 끊기지 않게 |
| 실제 기관 대신 가상 카드사, 번호 뒷자리 ● 처리 | 오해와 불안 방지 |

## 사전·사후 문제

- 유형당 1문항(문자·전화 5개 + AI 영상 1개), 총 6문항을 연습 전과 후에 똑같이 풉니다.
- 정답 위치를 섞어 같은 번호만 누르는 것을 막았습니다.
- "이 번호로 전화해서 목소리를 들어 본다"처럼 안전해 보이지만 틀린 오답을 넣었습니다. AI 음성 위조가 가능해져 목소리만으로는 가족인지 확인할 수 없기 때문입니다.
- 문제 풀이 중에는 정답을 알려 주지 않습니다. 사후 점수가 연습 효과를 보여 주게 하기 위해서입니다.

## 수상한 점 찾기 (AI 영상)

할머니 인터뷰에서 나온 문제는 "어떻게 대처할지"보다 **"가짜인지 알아보지 못한다"**는 것이었습니다. 그래서 AI 영상 시나리오는 선택이 끝난 뒤, 같은 영상을 다시 보며 수상한 곳을 직접 눌러 찾는 단계를 넣었습니다.

| 결정 | 이유 |
| --- | --- |
| 정답 단서 + 함정 영역 | 얼굴·조회수처럼 단서처럼 보이지만 판단 근거가 안 되는 곳을 누르면 "이것만으로는 알 수 없어요"라고 안내. 아무 데나 누르는 것을 막고, "얼굴이 진짜 같으면 믿어도 된다"는 오해를 바로잡음 |
| 손가락 6개 같은 AI 흔적은 단서 하나로만 | AI 영상은 점점 자연스러워지므로 흔적 찾기만 가르치면 위험. 나머지 단서는 기술이 좋아져도 남는 것(마감 압박, 확인할 수 없는 출처, 이상한 주소, 똑같은 후기)으로 구성 |
| 못 찾은 단서는 노란색으로 보여 주고 이유 설명 | 틀려도 배울 수 있게 |
| 찾은 개수·시간·정답 보기 여부 기록 | 어떤 단서를 어르신이 놓치는지 분석 |

## 가족 맞춤 연습

실제 자녀 사칭 사기는 가족 이름과 호칭을 알고 접근합니다. 자녀가 '가족 암호' 화면에서 호칭(엄마·아빠)과 이름을 넣어 링크를 만들면, 부모님 휴대폰에서 "아빠 나야, 민수"처럼 우리 집 상황으로 연습할 수 있습니다.

- 이름은 링크 주소 끝(`#fam=...`)에만 담기고 서버로 전송되지 않습니다. 링크를 열면 주소창에서 바로 지웁니다.
- 자녀가 부모님께 보내는 구조라, 앱이 가족을 통해 퍼질 수 있습니다.
- 사전·사후 문제는 비교를 위해 맞춤 이름을 쓰지 않습니다.

## 데이터 저장

연습 기록은 휴대폰 브라우저 안(`localStorage`)에만 저장합니다.

처음에는 진행자가 휴대폰을 건네 드리며 한 분씩 테스트하려 했지만, 여러 어르신이 각자 참여하실 수 있도록 바꿨습니다.

| 결정 | 이유 |
| --- | --- |
| 처음 화면의 '연습 효과 테스트 참여하기' 하나로 시작 | 링크를 사람마다 따로 보내지 않아도 QR 하나로 누구나 참여 |
| 참여자는 앱이 만든 번호(예: 참여자-7K2M)로 구별 | 이름·전화번호를 입력하게 하면 "링크에 개인정보를 넣지 말라"는 교육 내용과 모순됨 |
| 결과는 구글 시트로 자동 전송 ([만드는 법](sheet-setup.md)) | 어르신이 결과를 직접 보내지 않으셔도 데이터가 모임. 선생님은 보기 권한으로 결과만 확인 |
| 어르신 화면에는 점수 대신 감사 인사와 '멈춤·끊기·확인' | 점수가 떨어진 분이 실망하지 않도록, 결과는 진행자만 확인 |
| 인터넷이 끊겨 못 보낸 결과는 앱을 다시 열 때 자동 재전송 | 경로당 와이파이가 불안정할 수 있음 |
