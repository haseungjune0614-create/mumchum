# 테스트

## 방법

참여자: 어르신 3명 이상 (현재 2명 섭외, 1명 이상 추가 섭외 중)

1. **사전 문제**: 앱의 연구용 메뉴에서 참여자 번호를 넣고 5문항 풀기
2. **연습**: 시나리오 7개를 차례로 체험 (문자·전화 5개 + AI 영상 2개)
3. **가족 암호 정하기**
4. **사후 문제**: 같은 5문항 다시 풀기
5. **짧은 인터뷰**: 어려웠던 화면, 실제로 도움이 될 것 같은지, 더 넣고 싶은 사기 유형

## 측정 지표

- 사전·사후 평균 정답률과 참여자별 점수 변화
- 시나리오별 피해 결말에 이른 비율 (어떤 유형에 가장 잘 속는지)
- 문제 풀이 소요 시간
