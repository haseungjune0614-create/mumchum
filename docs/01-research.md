# 조사와 인터뷰

## 문제 정의

어르신은 사기 문자와 전화에 자주 노출되지만, 대응 방법을 "읽어서" 아는 것과 그 순간에 "행동하는" 것은 다릅니다. 사기범은 급하다고 몰아붙이거나 가족에게도 말하지 말라고 압박해서 생각할 틈을 주지 않습니다. 그래서 이 프로젝트는 압박받는 순간을 미리 겪어 보는 연습에 초점을 맞췄습니다.

## 할머니 인터뷰 (11월 7일)

- 최근 직접 받으신 사기 문자는 확인하지 못했습니다.
- 대신 **AI로 만든 허위 영상을 자주 보신다**는 점을 알게 됐습니다. 주로 **건강식품·약 광고**와 **가짜 뉴스·정치 영상**입니다.
- 이 결과로 문자·전화 사기 5개 유형은 통계를 근거로 정하고, AI 허위 영상 구별을 새 유형으로 추가하기로 했습니다.

## 선정한 사기 유형

| 유형 | 실제 수법 | 연습하는 대응 |
| --- | --- | --- |
| 자녀 사칭 문자 | "폰 액정이 깨져 임시폰이야" 후 신분증·카드번호 요구 | 저장된 원래 번호로 전화, 가족 암호 확인 |
| 부고·청첩장 문자 | 링크를 누르면 악성 앱 설치 유도 | 링크 누르지 않기, 지인에게 전화로 확인 |
| 택배 주소 확인 문자 | [국제발신] 재배송비 명목으로 카드 정보 입력 유도 | 쓰던 택배 앱·판매처에서 직접 확인 |
| 검찰 사칭 전화 | "통장이 범죄에 쓰였다", 안전계좌 이체·비밀 유지 요구 | 일단 끊고 112 또는 가족에게 알리기 |
| 카드 발급 문자 | 가짜 고객센터 → 금감원 사칭 → 원격조종 앱 설치 | 카드 뒷면 번호로 직접 전화 |
| AI 허위 영상 (추가 예정) | 건강식품·약 광고, 가짜 뉴스 영상 | 출처 확인, 구매·공유 전에 멈추기 |

기관사칭형이 피해액의 대부분을 차지해 검찰 사칭(전화)과 카드 발급(문자에서 전화로 이어짐) 두 경로를 모두 넣었고, 어르신이 가장 많이 받는 지인 사칭·링크형 문자를 나머지로 골랐습니다.
