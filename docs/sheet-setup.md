# 테스트 결과 받는 구글 시트 만들기

어르신이 테스트를 마치면 결과가 구글 시트에 자동으로 한 줄씩 쌓입니다. 선생님은 시트를 보기 권한으로 받아 결과만 확인합니다. 따로 서버를 두지 않고 구글 시트와 Apps Script(구글이 제공하는 작은 서버 코드)를 씁니다.

## 보내는 정보

| 보냄 | 보내지 않음 |
| --- | --- |
| 앱이 자동으로 만든 참여자 번호 (예: 참여자-7K2M) | 이름, 전화번호, 위치 |
| 사전·사후 점수, 고른 답 번호, 걸린 시간 | 가족 암호, 가족 맞춤 연습의 이름 |
| 상황별 결말(안전·아슬아슬·피해)과 고른 선택지 | 휴대폰 정보 |
| 수상한 점 찾기에서 찾은 단서 수 | |

## 1. 시트 만들기 (1분)

1. [sheets.google.com](https://sheets.google.com)에서 빈 스프레드시트를 만들고 이름을 `멈춤 연습장 테스트 결과`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.

## 2. 코드 붙여 넣기 (2분)

1. 편집기에 있던 `function myFunction() {}`를 모두 지웁니다.
2. 이 저장소의 [`scripts/sheet.gs`](../scripts/sheet.gs) 내용을 전부 붙여 넣습니다.
3. 위쪽 저장 아이콘을 누릅니다. 프로젝트 이름은 `멈춤 연습장 결과 수집`으로 합니다.

## 3. 웹 앱으로 배포하기 (3분)

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. '유형 선택' 옆 톱니바퀴 → **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `결과 수집`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르면 권한 승인 창이 뜹니다. 내 구글 계정 선택 → '확인되지 않은 앱' 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 누릅니다. 내가 만든 코드라서 나오는 경고입니다.
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. 확인: 그 주소를 브라우저에서 열어 `멈춤 연습장 결과 수집 중`이 보이면 성공입니다.

"모든 사용자"로 여는 이유: 어르신 휴대폰은 구글에 로그인하지 않은 상태에서도 결과를 보내야 하기 때문입니다. 이 주소로는 결과를 **추가만** 할 수 있고, 시트 내용을 읽을 수는 없습니다.

## 4. 앱에 주소 넣기

`index.html`에서 아래 줄을 찾아 따옴표 안에 복사한 주소를 넣고 push합니다.

```js
const SHEET_URL = "https://script.google.com/macros/s/.../exec";
```

주소가 비어 있으면 앱은 예전처럼 결과를 카카오톡으로 보내는 방식으로 동작합니다.

## 5. 먼저 직접 해 보기

1. 휴대폰에서 공개 주소를 열고 **연습 효과 테스트 참여하기**로 끝까지 진행합니다.
2. 마지막 화면에 "결과가 선생님께 전달됐어요"가 나오고, 시트에 `결과` 탭과 한 줄이 생기면 성공입니다.
3. 확인용 줄은 지웁니다. 같은 휴대폰으로 또 해 보려면 처음 화면의 "다른 분이 이 휴대폰으로 새로 하기"를 누릅니다.

## 6. 선생님께 공유하기

시트 오른쪽 위 **공유** → 선생님 이메일 → 권한을 **뷰어**로 → 보내기. 선생님은 결과를 볼 수만 있고 고치거나 지울 수 없습니다.

## 7. 요약 탭 (선택)

새 탭 `요약`을 만들고 아래 수식을 넣으면 참여자가 늘 때마다 자동으로 계산됩니다.

| 칸 | 내용 | 수식 |
| --- | --- | --- |
| A1 / B1 | 참여 인원 | `=COUNTA(결과!B2:B)` |
| A2 / B2 | 사전 평균 정답률 | `=AVERAGE(결과!D2:D)/6` |
| A3 / B3 | 사후 평균 정답률 | `=AVERAGE(결과!E2:E)/6` |
| A4 / B4 | 점수가 오른 사람 | `=COUNTIF(결과!F2:F,">0")` |
| A5 / B5 | 피해 결말 합계 | `=SUM(결과!M2:M)` |

B2, B3은 서식 → 숫자 → 퍼센트로 바꿉니다.

## 코드를 고쳤을 때

`sheet.gs`를 수정했다면 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 이렇게 하면 웹 앱 주소는 그대로 유지됩니다.
